Organ Acquisition Type Code

This variable is contained in the following files:
Medicare Provider Analysis and Review
SAS Name
ORGN_ACQSTN_IND_CD

The code indicating the type of organ acquisition received by the beneficiary during the stay.

Comments

This field is derived by checking for the presence of the organ acquisition revenue center codes (081x and 089x) on any of the claim records included in the stay.

Source: MedPAR (derived)

Code Code value

K2 Living donor kidney (revenue code 0811)
