MEDPAR Surgical Procedure Version Code 6

This variable is contained in the following files:
Medicare Provider Analysis and Review
SAS Name
SRGCL_PRCDR_VRSN_CD_6

The code is used to indicate if the surgical procedure code (variables called PRCDRCD1 -PRCDRCD25) is ICD-9-CM or ICD-10-PCS.

Comments

ICD-10 codes were used starting October 2015.

This field was new in 2011.

Source: NCH

Code Code value
Null/missing ICD-9-CM
9 ICD-9-CM
0 ICD-10-PCS
